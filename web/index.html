Latency = (frame display time, converted to the server clock) − (capture time encoded in the frame's 32-bit barcode). Clock offset between this machine and the server is measured over the unshaped control channel (min-RTT probe; ± = RTT/2). A stall is any gap > 200 ms between consecutively presented frames (same definition for all three players). Live-card statistics use the last 30 s; stall counts are since the last reset. Wire rate = bytes leaving the server's per-protocol tc queue.
